Rix Music mencari lagu di YouTube dari judul atau link, mengantrekannya, lalu memutarnya di server Discord kamu.

Undang Rix Music ke servermu

Client ID belum diisi. Buka index.html, lalu ganti ISI_CLIENT_ID_DI_SINI dengan Client ID aplikasimu.

Kamu perlu izin Manage Server di server tujuan.

  • Cari lewat judul lagu, link YouTube, atau playlist
  • Antrean, loop, acak, dan autoplay lagu serupa
  • Tombol kontrol langsung di pesan bot

Perintah

Semua perintah diawali tanda #. Singkatan ada di dalam tanda kurung.

Cara pakai

Tiga langkah, tidak perlu pengaturan tambahan.

  1. Undang bot

    Tekan tombol undang, pilih servermu, lalu setujui izin yang diminta.

  2. Masuk voice channel

    Bot hanya memutar lagu di channel tempat kamu sedang berada.

  3. Ketik #play

    Tulis judul atau tempel link YouTube. Lagu langsung diputar atau masuk antrean.

Siap memutar lagu?

Undang bot ke server dan coba perintah pertamamu.
